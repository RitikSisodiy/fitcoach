# Agent instructions

Before and during any work in this repository:
1. Read and follow `CODING_RULES.md`. It is the single source of truth for coding practices.
2. Get up to speed from `docs/CONTEXT.md`, `docs/PROGRESS.md` and `docs/TASKS.md`. Don't reread the whole codebase.
3. After a meaningful change, update `docs/PROGRESS.md` and `docs/TASKS.md`, plus `CODING_RULES.md` if you learned something new.
